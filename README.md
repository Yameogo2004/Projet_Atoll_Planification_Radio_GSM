# Planification Radio GSM/GPRS avec Atoll

## Contexte
Travail pratique réalisé dans le cadre du module "Technologie des réseaux mobiles" – ENSA Tétouan (4e année).

## Objectifs
- Simuler la couverture radio d'un réseau GSM/GPRS
- Analyser les interférences (rapport C/I)
- Configurer les paramètres d'antennes (puissance, hauteur, tilt)
- Utiliser les modèles de propagation Okumura-Hata et COST-Hata
- Réaliser des cartographies de couverture et histogrammes

## Outils utilisés
- Atoll (logiciel de planification radio)
- MATLAB/Simulink (pour les simulations complémentaires)

## Résultats clés
- Couverture radio optimisée sur une zone de ~33800 km²
- Analyse C/I pour réduire les interférences
- Allocation automatique des voisins simulée
